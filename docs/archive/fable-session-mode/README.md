# Արխիվ — «նստաշրջանային» (session) ռեժիմ

Այս թղթապանակը **կոդ չէ** և չի կոմպիլյացվում։ Ֆայլերը պահվում են `.txt` վերջավորությամբ դիտմամբ՝ որպեսզի ոչ `tsc`-ը, ոչ `oxlint`-ը դրանց չդիպչեն։

## Ի՞նչ է սա

2026 թ. նոյեմբերի 6–17-ը նախագծի վրա աշխատել է երկու զրույց՝ զուգահեռ և տարբեր ճարտարապետությամբ։ Երկրորդ զրույցի («Fable») աշխատանքը գրվել է ուղիղ `D:\asue-schedule`-ում և **երբեք git չի հասել**։ Նոյեմբերի 23-ին `git stash` + `git pull`-ից հետո դրա փոփոխությունները հետ են գնացել, իսկ այս երեք **նոր** ֆայլը մնացել է աշխատանքային թղթապանակում՝ որպես untracked մնացորդ։

`git stash`-ը առանց `-u` դրոշի untracked ֆայլեր չի պահում, ուստի **սկավառակի պատճենը միակն էր**։ Այս branch-ը ստեղծվել է հենց դրա համար՝ նախքան դրանք աշխատանքային պատճենից ջնջելը։

## Կարևորը՝ ինչու չեն աշխատում

Այս ֆայլերը դիմում են API-ների, որոնք ներկայիս կոդում **այլևս չկան**՝

- `sessionDateDigits`, `getScheduleDays`, `groupDaysByWeek` (`schedule.constants` / `schedule.utils`)
- `DEFAULT_DOCUMENT_SETTINGS`, `DocumentSignatory` (`settings.types`)

Ուղղակի հետ դնելը չի աշխատի։ Եթե session ռեժիմը վերադարձվի, այն գրվելու է նորից՝ ներկայիս ճարտարապետության վրա։ Այս ֆայլերի արժեքը **մոդելն է**, ոչ թե կոդը։
