# Ակադեմիական դասացուցակ

Համալսարանի ֆակուլտետների դասացուցակի կազմման և ցուցադրման համակարգ։

- **Ուսանողներ և դասախոսներ**. դիտում են դասացուցակը առանց մուտքի։ Հեռախոսում դասերը ցուցադրվում են օրերով, համակարգչում՝ աղյուսակով։ Կարելի է ներբեռնել PDF կամ ավելացնել Google/Apple օրացույց (.ics)։
- **Ֆակուլտետի ադմին**. խմբագրում է միայն իր ֆակուլտետի դասացուցակը։
- **Գլխավոր ադմին**. կառավարում է բոլոր ֆակուլտետները, օգտատերերին, պահուստային պատճենները և կարգավորումները։

## Տեխնոլոգիաներ

| Մաս | Տեխնոլոգիա |
|---|---|
| Frontend | React 19, TypeScript, Tailwind CSS 4, React Router 7, react-hook-form, axios, PWA (vite-plugin-pwa) |
| Backend | Node.js (≥ 22.18), TypeScript, SQLite (`node:sqlite`)։ **Արտաքին կախվածություններ չկան**, ուստի Windows-ում native build պետք չէ |

## Գործարկում (մշակման ռեժիմ)

```bash
npm install          # frontend-ի փաթեթները
npm run dev:server   # 1-ին տերմինալ. API-ն՝ http://localhost:4000
npm run dev          # 2-րդ տերմինալ. կայքը՝ http://localhost:5173
```

Առաջին գործարկման ժամանակ սերվերը ստեղծում է բազան (`server/data/schedule.db`), 6 ֆակուլտետները՝ կուրսերով, առարկաներով, դասախոսներով և լսարաններով, ինչպես նաև հաշիվները։ **Գաղտնաբառերը տպվում են կոնսոլում միայն մեկ անգամ**։ Պահպանեք դրանք։

| Մուտքանուն | Դեր |
|---|---|
| `superadmin` | Գլխավոր ադմին (գաղտնաբառը՝ `SUPER_ADMIN_PASSWORD`-ից կամ պատահական) |
| `karavarum`, `finans`, `tntesagitutyun`, `marketing`, `hashvapah`, `informatika` | Համապատասխան ֆակուլտետի ադմին |

Գաղտնաբառը փոխելու համար օգտագործեք ադմինի մենյուի «բանալի» կոճակը։ Գլխավոր ադմինը կարող է փոխել ցանկացած օգտատիրոջ գաղտնաբառը «Օգտատերեր» բաժնում։

## Արտադրական տեղադրում

```bash
npm install
npm run build        # TypeScript ստուգում + կայքի կառուցում (dist/)
cp server/.env.example server/.env   # լրացրեք SUPER_ADMIN_PASSWORD, NODE_ENV=production
npm start            # սերվերը մատուցում է և՛ կայքը, և՛ API-ն՝ նույն պորտում (4000)
```

- Սերվերը կարող է աշխատել ցանկացած VPS-ում (pm2 կամ systemd)։ Դրա առջևում դրեք nginx՝ HTTPS-ով (PWA-ն պահանջում է HTTPS) և միացրեք `TRUST_PROXY=true`։
- **GitHub Pages-ն այլևս հարմար չէ**, որովհետև այն չի կարող գործարկել սերվեր։ Եթե frontend-ը, միևնույն է, առանձին է տեղադրվում, նշեք `VITE_API_URL` (frontend) և `CORS_ORIGINS` (server)։
- Պարբերաբար պատճենեք `server/data/` թղթապանակը կամ օգտվեք «Պահուստավորում» էջից։

## Հին տվյալների տեղափոխում

Հին տարբերակում դասացուցակը պահվում էր միայն բրաուզերում։ Այն տեղափոխելու համար.

1. Հին կայքում մուտք գործեք որպես superadmin և սեղմեք **«📥 Backup JSON»** (DEV TOOLBAR-ում)։
2. Նոր կայքում բացեք **Կառավարում → Պահուստավորում → Վերականգնել / ներմուծել** և ընտրեք այդ ֆայլը։

Դասերը կավելացվեն համապատասխան ֆակուլտետներին և կուրսերին։ Անհրաժեշտության դեպքում հոսքերը և օրերը կավելացվեն ավտոմատ։

## Դասացուցակի կանոններ

- **Համարիչ / Հայտարար**. դասաժամը բաժանվում է կեսերի։ Ամբողջական դասը զբաղեցնում է ամբողջ դասաժամը, իսկ բաժանված դասի յուրաքանչյուր մաս՝ իր կեսը։ Նույն դասախոսը կամ լսարանը չի կարող կրկնվել նույն վանդակի մի քանի մասում։
- **Մասնաշենքեր**. յուրաքանչյուր ֆակուլտետ ունի իր մասնաշենքը։ Տարբեր ֆակուլտետների նույն համարով լսարանները (օր.՝ 202) տարբեր լսարաններ են։
- **Խաչվող դասեր չեն թույլատրվում բացարձակապես**. նույն ժամին նույն դասախոսը չի կարող լինել երկու տեղում (ամբողջ համալսարանում), իսկ նույն լսարանը՝ երկու տեղում (նույն մասնաշենքում)։ Նման դասը սերվերը չի պահպանում, և շրջանցելու հնարավորություն չկա։
- **Ոչ ակտիվ տարբերակներ**. դաս լրացնելիս ցուցակում զբաղված դասախոսներն ու լսարանները ցուցադրվում են ոչ ակտիվ՝ նշելով, թե որտեղ են զբաղված, և դրանք հնարավոր չէ ընտրել։
- **Առարկան** արգելափակված չէ. տարբեր խմբեր կարող են նույն ժամին ունենալ նույն առարկան՝ տարբեր դասախոսներով և լսարաններով։
- **Ձեռքով նշված լսարան**. լսարանը, որը չկա ֆակուլտետի ցուցակում, պահպանվում է միայն տվյալ դասում («ժամանակավոր») և չի ավելանում տեղեկատուին։ Լսարանների մշտական ցուցակը կառավարվում է «Տեղեկատու» էջից։ Նոր առարկաներն ու դասախոսները ավելանում են տեղեկատուին ավտոմատ։

## Ֆակուլտետներ, բաժիններ և դեկան

«Նոր ֆակուլտետ» պատուհանում ընտրվում է երկու տարբերակից մեկը.

- **Առանձին ֆակուլտետ** — նոր ֆակուլտետ՝ 5 կուրսերով, դեկանի անունով և իր մասնաշենքով։ Դեկանի դաշտը
  առաջարկում է արդեն գրանցված դեկանների անունները։
- **Կցել ֆակուլտետի** — բաժին գոյություն ունեցող ֆակուլտետի ներսում (օր.՝ «Հեռակա»)։ Բաժինը երևում է մայր
  ֆակուլտետի քարտի ներսում՝ առանձին խմբով, և ստեղծվում է 5 կուրսերով։

Բաժնի լսարանները կարող են լինել **մայր ֆակուլտետի** (նույն մասնաշենքը՝ խաչվող դասերը ստուգվում են միասին)
կամ **առանձին** (սեփական մասնաշենք՝ նույն համարով լսարանը ուրիշ լսարան է)։ Դասախոսի բախումը ստուգվում է
համալսարանական մակարդակով՝ անկախ մասնաշենքից։

## Հրապարակում (ֆակուլտետ, բաժին և կուրս)

Գլխավոր ադմինի ստեղծած **նոր ֆակուլտետը, բաժինը և կուրսը սևագիր են**։ Դրանք չեն երևում ոչ ուսանողների
(հանրային տեսք), ոչ էլ ֆակուլտետների ադմինների մոտ՝ մինչև **«Հրապարակել»** կոճակը սեղմելը։ Սևագիր կուրսի
դասերը չեն երևում նաև դասախոսի հանրային դասացուցակում։

Հրապարակումը հասանելի է «Վահանակ», «Ֆակուլտետներ» և դասացուցակի խմբագրման էջերից։ Հրապարակվածը կարելի է
հետ բերել սևագրի («Թաքցնել»)՝ առանց տվյալները ջնջելու։ Սերմնացված և պահուստից վերականգնված տվյալները
հրապարակված են։

## Ուսումնական պլան և ժամահաշվարկ

Յուրաքանչյուր կուրս ունի ուսումնական պլան՝ դասընթացները կիսամյակային ժամաքանակով, շաբաթվա օրերը և
դասաժամերի ժամերը։ Պլանը կառավարում է **միայն գլխավոր ադմինը** («Ուսումնական պլան» էջից կամ «Տեղեկատու»
էջում կուրս ընտրելով)։

**Հաստատում**. փոփոխությունները մնում են սևագիր։ Մինչև «Հաստատել» սեղմելը դրանք չեն երևում ոչ ֆակուլտետների
ադմինների, ոչ էլ ուսանողների մոտ (հանրային տեսքում)։ Հաստատումից հետո պլանի օրերն ու ժամերը կիրառվում են
կուրսի աղյուսակին, իսկ աղյուսակից դուրս մնացած դասերը ջնջվում են։ Չհաստատված փոփոխությունները կարելի է
չեղարկել՝ վերադառնալով վերջին հաստատված տարբերակին։

**Ժամահաշվարկ (առկա բակալավրիատ)**. կիսամյակը 16 շաբաթ է, մեկ մուտքը՝ 2 լսարանային ժամ, հետևաբար՝

```
շաբաթական մուտք = ժամաքանակ / 2 / 16 = ժամաքանակ / 32
```

| Ժամաքանակ | Շաբաթական մուտք | Ինչպես է լրացվում |
| --------- | --------------- | ----------------- |
| 16 ժամ    | 0,5             | կես մուտք (համարիչ/հայտարար) |
| 32 ժամ    | 1               | 1 ամբողջ մուտք (առանց համարիչ/հայտարարի) |
| 48 ժամ    | 1,5             | 1 ամբողջ + կես մուտք |
| 64 ժամ    | 2               | 2 ամբողջ մուտք |
| 80 ժամ    | 2,5             | 2 ամբողջ + կես մուտք |

16-ի պատիկները տալիս են ամբողջ կամ կես մուտք, բայց ժամաքանակը կարելի է գրել նաև **ձեռքով**՝ ցանկացած
արժեքով (օր.՝ 20 ժամ → 0,6 մուտք)։ Սահմանաչափը գործում է **յուրաքանչյուր հոսքում առանձին**՝ կուրսի բոլոր
հոսքերում առարկան անցնում է հավասարաչափ ժամերով։ Ժամաքանակը գերազանցող դասը սերվերը չի պահպանում, իսկ
խմբագրիչը ցույց է տալիս, թե հոսքում որքան է արդեն լրացված։

Երբ կուրսն ունի հաստատված պլան, դաս լրացնելիս առարկաների ցուցակում առաջարկվում են **միայն պլանի
առարկաները**, ոչ թե ֆակուլտետի ամբողջ տեղեկատուն։

## Դասացուցակի տեսքերը

Դասացուցակը ցուցադրվում է երեք տեսքով (ընտրիչը՝ աղյուսակի վերևում).

- **Պաշտոնական** — ՀՊՏՀ-ի ձևաչափը. տողերում՝ շաբաթների համարները և իրական ամսաթվերը, սյունակներում՝
  դասաժամերը՝ «Առարկա / Դասախոս / Լսարան» ենթասյունակներով, մեկ աղյուսակ՝ մեկ հոսքի համար։ Հանրային էջում
  այս տեսքն է բացվում ըստ նախնականի։
- **Շաբաթական** — կոմպակտ աղյուսակ (օրեր × դասաժամեր, հոսքերը՝ սյունակներում)։ Խմբագրումը կատարվում է
  այստեղ. մեկ անգամ լրացված դասը ինքնաբերաբար բացվում է ամբողջ կիսամյակի վրա։
- **Օրերով** — հեռախոսի համար՝ օրերի քարտեր։

**Համարիչ/Հայտարար**. «Համարիչ» մասը անցնում է **կենտ** շաբաթներին (1, 3, 5 …), «Հայտարար»-ը՝ **զույգ**
շաբաթներին (2, 4, 6 …)՝ կիսամյակում 8-ական շաբաթ։ Ամսաթվերը հաշվվում են «Կարգավորումներ» բաժնի կիսամյակի
սկզբից և շաբաթների քանակից։

Արտահանումը վերցնում է ընտրված տեսքը (PDF, տպում), իսկ «Excel (պաշտոնական ձև)»-ը ստեղծում է ֆայլ՝
յուրաքանչյուր հոսքի համար առանձին թերթով։

## Դասացուցակ և քննագրաֆիկ

Կուրս մուտք գործելիս բացվում է երկու առանձին պատուհան՝ **Դասացուցակ** և **Քննագրաֆիկ**։ Քննական գրաֆիկի
բովանդակությունը կավելացվի առանձին փուլով։

## Թեստեր

```bash
npm test             # API-ի ինտեգրացիոն թեստեր (դերեր, բախումներ, պլան, բաժիններ, հրապարակում)
npm run typecheck    # TypeScript ստուգում (frontend)
```

## Կառուցվածք

Կոդը բաժանված է ըստ մոդուլների։ Ֆայլերի անունները kebab-case են՝ `{name}.{role}.ts`։

```
src/
  app/                      # router, route-երի աղյուսակ, provider-ներ
  modules/
    auth/                   # auth.constants.ts, auth.requests.ts, auth.context.tsx, guards/, pages/
    schedule/               # schedule.types.ts, schedule.requests.ts, schedule.utils.ts, components/, hooks/, services/, pages/
    curriculum/             # ուսումնական պլան՝ ժամաքանակ, հաստատում, քվոտաների հաշվարկ
    divisions/              # ֆակուլտետին կցված բաժիններ (server-ում)
    exams/                  # քննագրաֆիկ
    faculties/ catalog/ reports/ change-log/ users/ backup/ settings/ dashboard/
    common/                 # http-client (axios), UI կոմպոնենտներ, layout-ներ, hooks
server/src/
  core/                     # http router, database, security (JWT, scrypt), validation
  modules/                  # նույն սկզբունքով՝ {name}.repository.ts, {name}.service.ts, {name}.controller.ts
  seed/                     # սկզբնական տվյալներ
```

Կիրառված սկզբունքներ.

- **Repository → Service → Controller** շերտեր (SRP)։
- Կախվածությունները միացվում են մեկ տեղում՝ `server/src/app.ts` (Dependency Injection)։
- `httpClient`-ը չգիտի auth-ի մասին. token-ը գրանցվում է auth մոդուլից (DIP)։
- Հետարկել/Կրկնել գործողությունները կառուցված են **Command** pattern-ով։
- Guard-երը կազմված են փոքր, իրար հետ համադրվող բաղադրիչներից (`RequireAuthGuard`, `RequireRoleGuard`, `GuestOnlyGuard`)։
- Իրավունքները ստուգվում են **սերվերում**։ Frontend-ի guard-երը միայն թաքցնում են անհասանելի էջերը։
